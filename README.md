# Gather – Event Manager

A responsive event and guest-invitation manager built with HTML, CSS and vanilla JavaScript.

## Features
- Create and delete events; select an event to manage it
- Invite guests, change RSVP status (Pending / Going / Maybe / Declined)
- Live RSVP statistics and guest search
- Data persists in the browser (localStorage)
- Responsive layout using CSS Grid and Flexbox

## Run it
Open `index.html` in any browser. No install needed.

## Structure
- `index.html` – page structure
- `style.css`  – styling, Grid/Flexbox layout, media queries
- `script.js`  – state, DOM rendering, event handling
